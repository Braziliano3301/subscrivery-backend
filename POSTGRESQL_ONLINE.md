# PostgreSQL Online Grátis - Neon (RECOMENDADO)

## Por que usar?
- ✅ Sem instalação
- ✅ Grátis
- ✅ Funciona em 2 minutos
- ✅ Já está em produção (não precisa migrar depois)

## Passo a Passo:

### 1. Criar conta (1 minuto)
1. Abrir: https://neon.tech
2. Clicar "Sign Up"
3. Entrar com GitHub ou Google (mais rápido)

### 2. Criar projeto (30 segundos)
1. Nome do projeto: `subscrivery`
2. Region: escolher qualquer uma
3. Clicar "Create Project"

### 3. Copiar credenciais (30 segundos)
Vai aparecer uma string de conexão tipo:
```
postgresql://user:password@ep-xxx.us-east-2.aws.neon.tech/neondb
```

**Copiar essa string!**

### 4. Abrir SQL Editor no Neon
1. No menu lateral: "SQL Editor"
2. Cole TODO o conteúdo do arquivo: `C:\Users\Usuario\OneDrive\Desktop\Subscrivery\docs\database\schema.sql`
3. Clicar "Run"
4. Pronto! ✅

### 5. Configurar .env
Vou fazer isso pra você! Só me passa a string de conexão que o Neon te deu.
